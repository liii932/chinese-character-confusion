## 实验目标与范围

本轮用于确认数据、Colab GPU 训练、开发集评价和检查点保存流程可用，并判断是否存在足够的形近字混淆以进入后续方法比较。

- 54 个预设字对的端点覆盖全部 81 字，因此没有独立的普通字对照集合。

## 数据配置与划分

数据版本为 `baseline81-v2`，划分种子为 `20261012`。共 46,656 张 64×64、8 位灰度、白底黑字图片。

| 集合 | 每类数量 | 总量 | 本轮用途与状态 |
|---|---:|---:|---|
| train | 192 | 15,552 | 基线梯度更新 |
| val_select | 96 | 7,776 | 开发期选取最佳检查点，已评估 |
| val_graph | 96 | 7,776 | 基线选定后分析混淆，已评估 |
| test | 192 | 15,552 | 已生成，尚未进行最终模型评估 |

渲染采用 256×256 四倍画布、统一字号 192 px（输出尺度 48 px）及共同基线 `[32, 200]`，不逐字裁剪拉伸。平移为横纵各 ±3 px、步长 0.25 px；Lanczos 下采样后应用 sigma=0、0.5、1.0 的高斯模糊，模糊前补 16 px 白边再裁回。各类别、各集合的三档模糊均等量。输入归一化为 `(x / 255 - 0.5) / 0.5`，无额外在线增强。

所有类别共享条件表，先检查像素重复再分配集合。独立复核得到 46,656 个唯一像素哈希，无跨标签或跨集合相同图；生成时未发现空图或裁剪。各集合／sigma 的横纵偏移均值绝对值不超过 0.25 px，两侧均覆盖至至少 ±2.5 px。60 张抽样与原核验渲染函数逐像素一致，详见[流程验证记录](../../VALIDATION.md)。

这些图片来自固定字模的相关变体。像素不重复不等于独立真实字形采样；本次结果反映固定生成机制下未参与训练的条件组合表现。

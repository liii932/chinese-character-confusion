# 81 字形近汉字识别首轮基线实验记录

记录日期：2026-10-12（Asia/Shanghai）

实验编号：`baseline81_s42_v1`

状态：40 epoch 训练与两个开发集评估已完成；本轮结果已整理归档，测试集尚未使用。

本次实验在固定思源黑体及预设位置、模糊条件下，用 ResNet18 进行 81 类单字识别。最佳检查点为第 38 轮，在 `val_select` 和 `val_graph` 上均达到 100% 准确率；后者误认总数及有效混淆目标数均为 0。当前数据条件下没有可用于候选针对性训练的混淆关系，因而本轮没有开展方法对照，也不能据此判断针对性方法是否有效。

## 实验目标与范围

本轮用于确认数据、Colab GPU 训练、开发集评价和检查点保存流程可用，并判断是否存在足够的形近字混淆以进入后续方法比较。

- 字表为已核验的 81 字，类别 ID 为 0～80，沿用原始标签顺序；人工预设重点字对为 54 对。
- 字体固定为思源黑体 SC Regular 2.005，不涉及陌生字体、手写字或真实拍照 OCR。
- 本轮仅完成一个训练种子 42；没有跨种子重复实验，也没有统计显著性结论。
- 54 个预设字对的端点覆盖全部 81 字，因此没有独立的普通字对照集合。

## 数据配置与划分

数据版本为 `baseline81-v2`，划分种子为 `20261012`。共 46,656 张 64×64、8 位灰度、白底黑字图片。

| 集合 | 每类数量 | 总量 | 本轮用途与状态 |
|---|---:|---:|---|
| train | 192 | 15,552 | 基线梯度更新 |
| val_select | 96 | 7,776 | 开发期选取最佳检查点，已评估 |
| val_graph | 96 | 7,776 | 基线选定后分析混淆，已评估 |
| test | 192 | 15,552 | 已生成，尚未进行最终模型评估 |

渲染采用 256×256 四倍画布、统一字号 192 px（输出尺度 48 px）及共同基线 `[32, 200]`，不逐字裁剪拉伸。平移为横纵各 ±3 px、步长 0.25 px；Lanczos 下采样后应用 sigma=0、0.5、1.0 的高斯模糊，模糊前补 16 px 白边再裁回。各类别、各集合的三档模糊均等量。输入归一化为 `(x / 255 - 0.5) / 0.5`，无额外在线增强。

所有类别共享条件表，先检查像素重复再分配集合。独立复核得到 46,656 个唯一像素哈希，无跨标签或跨集合相同图；生成时未发现空图或裁剪。各集合／sigma 的横纵偏移均值绝对值不超过 0.25 px，两侧均覆盖至至少 ±2.5 px。60 张抽样与原核验渲染函数逐像素一致，详见[流程验证记录](../../VALIDATION.md)。

这些图片来自固定字模的相关变体。像素不重复不等于独立真实字形采样；本次结果反映固定生成机制下未参与训练的条件组合表现。

## 研究结论与本轮决定

基线模型在当前 81 字、固定字体和合成条件下已达到两个开发集的准确率上限。当前没有观察到可供候选训练方法利用的混淆关系。

按照设计书的损失定义，B 组的所有类别错误率为 0，权重均为 1；C、D 组因 `S` 为空而辅助损失均为 0。因此 B/C/D 的目标都退化为 A 的普通交叉熵继续训练。本轮没有运行 A/B/C/D 正式方法对照，也无法据此证明针对性方法有效或无效。

这一结论限于单个训练种子和当前开发条件，不能外推为真实拍照、其他字体、未见汉字或最终测试表现。两个开发集的样本数虽各为 7,776，仍属于固定字模的相关变体。
